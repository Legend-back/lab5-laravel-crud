# Descripción
Proyecto base de Laravel para practicar una API REST sencilla y un CRUD de tareas Tasks usando almacenamiento en archivos sin base de datos.  
Se trabaja con rutas en `routes/api.php`, controladores y un repositorio que maneja la persistencia.
